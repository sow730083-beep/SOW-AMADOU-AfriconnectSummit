## Description du Projet
Développement du site vitrine complet d'une conférence tech panafricaine fictive nommée **« AfriConnect Summit »**, accueillant des développeurs, entrepreneurs et investisseurs. Le site comporte 4 pages interconnectées, modernes, fluides et responsives.

## Fonctionnalités JavaScript Implémentées
1. **Dark Mode / Light Mode :** Géré via des variables CSS et persistant d'une page à l'autre grâce au `localStorage`.
2. **Navbar Dynamique :** Changement de fond et d'ombre après 80px de défilement.
3. **Menu Hamburger :** Navigation mobile parfaitement fonctionnelle au clic.
4. **Compte à Rebours :** Horloge en temps réel sur la page d'accueil calculant le temps restant avant l'événement.
5. **Onglets de Programme :** Affichage dynamique du planning des 3 jours sans rechargement de page.
6. **Filtrage Dynamique :** Tri des cartes d'intervenants en temps réel par thématique (Tous, IA, Business, Design, Data).
7. **Validation de Formulaire :** Vérification stricte des données avec retours visuels (bordures de couleurs) et messages d'erreurs dédiés.
8. **Bouton Retour en Haut :** Apparition fluide après 300px de scroll pour remonter doucement en haut de page.
9. **Année Dynamique :** Injection automatique de l'année en cours dans le footer de toutes les pages.

## Contraintes Techniques Respectées
- HTML5 sémantique sans abus de `<div>`.
- Un seul fichier CSS externe avec plus de 8 variables CSS natives.
- Utilisation intensive de Flexbox et de CSS Grid (grille asymétrique et responsive).
- Intégration de Google Fonts (Syne et Inter) et d'icônes via Bootstrap Icons.
- FAQ en accordéon réalisée en **CSS pur** (sans aucun JavaScript via l'astuce `:checked`).
